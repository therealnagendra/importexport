# Project Report

## Title
Import-Export Documentation & Management System

## Abstract
This project is a desktop-local web application created for managing import and export operations. It stores data in SQLite and supports user, shipment, document, and report workflows.

## Technology Stack
- Python 3.11
- Flask
- SQLite via Python sqlite3
- Jinja2 templates
- HTML, CSS, and JavaScript
- pytest

## Modules
- Authentication
- Dashboard
- Shipment management
- Party management
- Agent management
- Document management
- Tracking
- Expense management
- Reporting

## Installation
Please follow README.md.

## Testing
